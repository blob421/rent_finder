RENT FINDER 
============================

Description
----------------------------
This bot is specialized in finding the best appartment for rent in quebec city
based on user defined criterias.


Setup
----------------------------

- Run main.py and follow prompts
- Configs are saved in /config.json

Features
-----------------------------

- Doesn't run in headless mode by default , this is to bypass bots protection on rentals.ca
- Sends notifications to desktop when a match was found.

Tweakables
-----------------------------
- Tweakable price range 
- Target a specific postal code 
- Match a keyword in an appartment description or address.
